# 구글 드라이브 자동 백업 설정

"하루 하루 삶의 기록"(`life/`)과 "책읽는 삶의 재미"(`books/`)는 자료를 저장할 때마다
내 구글 드라이브에 자동으로 백업할 수 있습니다. 구글 **Apps Script** 웹 앱을 한 번 만들어 두면 됩니다.
(구글 클라우드 콘솔에서 따로 만들 것은 없습니다.)

## 1. Apps Script 웹 앱 만들기 (컴퓨터에서 하는 것이 편함)

1. <https://script.google.com> 에 앱에서 쓸 구글 계정으로 들어가 **새 프로젝트**를 누릅니다.
2. 왼쪽 위 프로젝트 이름을 `삶의 기록 백업` 등으로 바꿉니다.
3. `Code.gs`의 내용을 모두 지우고 [`drive-backup.gs`](drive-backup.gs)의 내용을 붙여 넣습니다.
   (앱의 **관리 → 백업 · 복원 → 설정 방법 보기 → Apps Script 코드 복사**로도 복사할 수 있습니다.)
4. 맨 위 `SECRET` 의 글자를 **나만 아는 긴 글자**로 바꿉니다. 예: `haru-2026-나의-비밀-7391`
   이 글자가 비밀번호 역할을 하니 남에게 알려 주지 마세요.
5. 💾 저장(Ctrl+S)을 누릅니다.
6. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 톱니바퀴(유형 선택) → **웹 앱**
   - 설명: `백업` (아무 글자)
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누릅니다.
7. **액세스 승인**을 누르고 구글 계정을 고릅니다.
   "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용**을 누릅니다.
   내가 만든 스크립트라서 나오는 안내이고, 이 스크립트는 내 드라이브의 "삶의 기록 앱 백업" 폴더에만 씁니다.
8. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 2. 앱에서 켜기 (탭에서)

1. 앱의 **관리 → 백업 · 복원**을 엽니다.
2. **구글 드라이브 자동 백업** 칸에 웹 앱 URL과 SECRET 글자를 넣고 **연결하고 켜기**를 누릅니다.
3. "켜짐"이 보이면 끝입니다. 한 앱에서 켜면 같은 브라우저의 다른 앱도 함께 켜집니다.
   (홈 화면에 설치한 앱과 크롬은 같은 저장 공간을 씁니다. 다른 브라우저나 다른 기기에서는 한 번 더 넣습니다.)

## 동작 방식

- 저장할 때마다 몇 초 뒤 전체 자료를 보냅니다. 인터넷이 끊겼으면 다시 연결될 때나 다음에 앱을 열 때 보냅니다.
- 드라이브의 **삶의 기록 앱 백업** 폴더에 저장됩니다.
  - `하루하루삶의기록-latest.json`, `책읽는삶의재미-latest.json` : 가장 최근 백업
  - `…-2026-10-04.json` : 날짜별 백업 (90일 지나면 휴지통으로)
  - `…-줄어들기전-시각.json` : 기록 수가 줄어든 백업이 오면 덮어쓰기 전 내용을 따로 남김
- 새 브라우저(새로 설치한 앱, 새 기기)에서 처음 연결하면 드라이브의 백업을 먼저 **합쳐서 복원**한 뒤 올립니다.
  그래서 빈 앱에서 저장해도 드라이브의 기록이 지워지지 않습니다.
- 앱의 **드라이브에서 불러오기**로 가장 최근 백업을 "합쳐서 복원" 또는 "백업으로 바꾸기" 할 수 있습니다.

## 코드를 고쳤을 때

Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 눌러야 반영됩니다.
(이렇게 하면 웹 앱 URL은 그대로입니다. "새 배포"를 하면 URL이 바뀌니 앱에 다시 넣어야 합니다.)
